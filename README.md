# EWIL Cornell Website

Free static website for GitHub Pages.

## Publish
1. Create a GitHub repository, e.g. `ewil-cornell-website`.
2. Upload all files and the `assets` folder.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
5. GitHub will provide the live website address.

## Update later
Edit the relevant HTML file and commit the change. GitHub Pages republishes it automatically.
